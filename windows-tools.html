Set up Windows with WSL

Windows runs your apps; Ubuntu in WSL runs your developer tools. Use PowerShell only where this page says so, and use Ubuntu for every other command.

1 — Install Ubuntu through WSL

Open Start, search for PowerShell, right-click it, and choose Run as administrator. This is needed once because Windows is enabling an operating-system feature.

wsl --install -d Ubuntu

wsl is Windows’ tool for Linux environments. --install enables WSL; -d means “distribution”, and Ubuntu is the Linux version to install. Restart if Windows asks. When Ubuntu first opens, choose a Linux username and password. From now on, open Ubuntu from Start for guide commands.

2 — Update Ubuntu

sudo apt update

sudo temporarily gives this one Ubuntu command administrator permission. apt is Ubuntu’s package manager; update downloads its current software list without installing anything. Your password stays invisible as you type.

sudo apt upgrade -y

upgrade updates software already installed. -y accepts its normal confirmation automatically.

3 — Install Python and Git

sudo apt install -y python3 python3-pip python3-venv git

install adds software. python3 runs Python, python3-pip installs Python libraries, python3-venv creates isolated project environments, and git records your code history. -y

4 — Install current Node.js

These commands add NodeSource’s signed repository, then install Node. Run one command at a time.

sudo apt install -y ca-certificates curl gnupg

ca-certificates verifies secure websites, curl downloads web addresses in the terminal, and gnupg verifies signed software sources.

sudo mkdir -p /etc/apt/keyrings

mkdir makes a folder. -p

curl -fsSL https://deb.nodesource.com/gpgkey/nodesource-repo.gpg.key | sudo gpg --dearmor -o /etc/apt/keyrings/nodesource.gpg

curl downloads NodeSource’s public signing key. -f fails on web errors, -sS hides routine output but shows errors, and -L follows redirects. The | passes the download to gpg; --dearmor converts it and -o names the saved file.

NODE_CODENAME=$(awk -F= '/^VERSION_CODENAME=/{print $2}' /etc/os-release)

This saves Ubuntu’s release name in a temporary variable. It does not install or send anything.

echo "deb [signed-by=/etc/apt/keyrings/nodesource.gpg] https://deb.nodesource.com/node_22.x $NODE_CODENAME main" | sudo tee /etc/apt/sources.list.d/nodesource.list

echo produces the repository address. $NODE_CODENAME is replaced by the release name saved above. tee writes it into apt’s protected source-list folder.

sudo apt update

This makes apt read the new Node.js source.

sudo apt install -y nodejs

This installs Node.js and npm from that signed source.

5 — Install VS Code on Windows

Open a normal PowerShell window, not Ubuntu, for this command:

winget install --id Microsoft.VisualStudioCode -e

winget is Windows’ package manager. install adds an app. --id selects VS Code’s exact catalogue name, and -e means “exact match”. In VS Code, install the Remote - WSL extension, then choose its “Open a Remote Window” option and select Ubuntu. Install Python, Pylance, Ruff, and GitLens in that WSL window.

6 — Verify in Ubuntu

Open Ubuntu again. Each command should print a version number; --version only asks a program to identify itself.

python3 --version
node --version
git --version
code --version

If code is not found, first open any Ubuntu folder in VS Code through Remote - WSL, then try again. Do not continue until each command works.
