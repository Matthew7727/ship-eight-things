Set up your Mac

Use only these Mac instructions. Run one command, read its explanation, wait for it to finish, then continue.

1 — Apple developer tools

These provide the low-level tools other developer software needs. A macOS window will ask you to confirm the download.

xcode-select --install

xcode-select manages Apple’s developer-tool location; --install asks macOS to install the command-line tools, not the large Xcode application. Click Install when macOS asks.

2 — Homebrew

Homebrew installs developer software on Mac. This is the one deliberately long command because it is Homebrew’s official installer; read it before you run it.

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

/bin/bash starts a shell; -c runs the text that follows. curl downloads Homebrew’s installer from its official address; -f fails on an error, -sS hides routine output but shows errors, and -L follows redirects. $(...) passes the downloaded installer to the shell.

When it completes, make Homebrew available in future Terminal windows:

echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile

echo produces text. >> adds it to ~/.zprofile, a file Terminal reads when it opens. ~ means your home folder.

eval "$(/opt/homebrew/bin/brew shellenv)"

This applies Homebrew’s setup in this Terminal now. $(...) gets the setup text and eval applies it.

3 — Install the developer tools

Each uses the same pattern: brew runs Homebrew, install adds software, and the final word is the package name.

brew install python

Python runs the first four projects.

brew install node

Node.js runs JavaScript outside the browser. npm is included with it and becomes useful later.

brew install git

Git records the history of your code.

brew install --cask visual-studio-code

--cask says this is a full Mac app rather than a terminal-only tool.

4 — Make VS Code available in Terminal

Open VS Code from Applications. Press ⇧ ⌘ P, search for Shell Command: Install 'code' command in PATH, and choose it. PATH is the list of folders Terminal searches when you type a command.

5 — Verify one command at a time

Each should print a version number. --version means “tell me which version is installed”; it does not change anything.

brew --version
python3 --version
node --version
git --version
code --version

If a command says “not found”, close Terminal, reopen it, and try that one command again. Do not continue until it works.
