Windows intro

Get comfortable with Windows before you start coding. You will use Windows for your apps and WSL’s Ubuntu terminal for development.

The basics

The desktop and Start menu

The taskbar is the strip along the bottom of the screen. It holds pinned apps, open windows, Wi-Fi, sound, battery, and the clock. Click an app icon to open it or bring it forward.

Press the Windows key to open Start, then type the name of an app or setting. This is the quickest way to open File Explorer, Settings, Windows Terminal, or VS Code.

Apps and windows

Closing a window normally closes that app. If an app remains in the notification area near the clock, right-click its icon and choose Exit if you need to stop it completely.

Files

File Explorer and files

File Explorer is Windows’ file manager. Open it with Windows E. The left sidebar provides quick access to Desktop, Documents, Downloads, and drives.

1

Show file extensions

In File Explorer, choose View → Show → File name extensions. You must be able to distinguish notes.txt from notes.py.

2

Keep code in Linux, not in Downloads

The projects in this guide belong in your WSL home folder, such as ~/code, not under C:\Users\.... You will open that folder from VS Code through WSL in the next step.

Use File Explorer for ordinary files. For project files, use VS Code and the Ubuntu terminal so file names, permissions, and tools behave consistently.

Windows

Window management

Windows can snap apps into a tidy layout. Drag a window to an edge or press Windows Left or Windows Right to place it on that side. Press Windows Up to maximise and Windows Down to restore or minimise.

Hover over the maximise button to choose a snap layout. Keeping VS Code and a browser side by side is useful when following the guide.

The terminal

Windows Terminal and WSL

Windows Terminal is the app that hosts command-line shells. For this guide, use its Ubuntu profile, supplied by Windows Subsystem for Linux (WSL). It gives you a real Linux development environment while keeping Windows for desktop apps.

Open Start, type Ubuntu, and press Enter after completing the setup on the next page. A prompt ending in $ means Ubuntu is ready for a command.

pwd

It prints your current folder, normally something like /home/your-name. A ~ means that same home folder.

Use the right terminal

Run guide commands in Ubuntu unless a step explicitly says to use PowerShell as Administrator. PowerShell commands and Linux commands look similar in places but are not interchangeable.

Before you code

Settings to change now

1

Run Windows Update

Open Settings → Windows Update, install available updates, and restart if prompted. WSL setup is more reliable on an up-to-date system.

2

Turn on clipboard history

Open Settings → System → Clipboard and enable Clipboard history. Press Windows V to reuse copied commands when you need it.

3

Keep notifications quiet while coding

Open Settings → System → Notifications and use Do not disturb for focused sessions.
